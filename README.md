# Movie Rating Application

This is a web application that allows users to browse a catalog of movies, track their viewing history, and rate films based on what they like and dislike.

## System Context 

This application is **not a standalone system**. It functions as an interactive review layer that bridges the gap between user sentiment and external media platforms. While users rate and comment on movies directly within this app, the system integrates with external movie websites, redirecting users to official platforms to view or purchase the films.

### Core Features
* **Emoji Rating System:** Users can quickly rate movies using three distinct interactive buttons: a smiley face (positive), a neutral face (indifferent), and a mad face (negative).
* **Movie Search Bar:** A dynamic search feature that allows users to quickly look up and discover new or previously watched movies.
* **Community Comment Section:** A public forum under each movie where users can leave detailed written reviews to share thoughts with other members.
* **External Website Integration:** Clickable movie titles or posters that seamlessly direct users to external official websites to watch the film.
